# Ceedoku Mono

Ceedoku Mono is a modified version of Roboto Mono by The Roboto Mono Project Authors.

**Modification:** The diagonal line in the zero (`0`) glyph has been removed.

Original project: https://github.com/googlefonts/roboto-classic
